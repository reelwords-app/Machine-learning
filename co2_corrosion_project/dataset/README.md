# Dataset: `co2_corrosion_dataset.csv`

6,000 rows. Generated by `generate_dataset.py` — see that file's module
docstring and `../paper/high_level_paper.md` ("Dataset Construction —
Transparency Statement") for full methodology.

## Provenance / "where did this row come from?"

This dataset is **model-derived from published, peer-reviewed empirical
correlations** — it is not a collection of measurements extracted from
individual papers (the environment used to build this project could not fetch
full paper text; see `../references/README.md`). Every row therefore carries
explicit reference-ID columns pointing to the exact correlation(s) used to
compute it. Reference IDs match the `id` column in `../references/references.csv`.

| Column | What it records | Cited references |
|---|---|---|
| `corrosion_rate_dewaard1975_mmpy` | Output of the de Waard–Milliams (1975) base correlation `log10(Vcorr)=5.8-1710/T+0.67·log10(pCO2)` | R017, R018, R020–R023 |
| `corrosion_rate_dewaard1995_mmpy` | Output of the de Waard (1995) correlation with explicit pH correction `log10(Vcorr)=4.93-1119/T+0.58·log10(pCO2)-0.34·(pH_actual-pH_sat)` | R020 |
| `corrosion_rate_target_mmpy` | "Consensus" target = geometric mean of the two model outputs above | (derived; see paper §3) |
| `model_disagreement_ratio` | Ratio between the two models' outputs for that row | (derived; see paper §5) |
| `source_dewaard1975_refs` | Reference IDs backing the 1975 correlation | R017;R018;R020;R021;R022;R023 |
| `source_dewaard1995_refs` | Reference IDs backing the 1995 correlation | R020 |
| `source_flow_correction_refs` | Reference backing the wall-shear-stress flow-sensitivity scaling `R_COR=a·τ_w^b` | R064 |
| `source_salinity_correction_refs` | References backing the salinity ("salting-out") damping term | R109;R110;R111;R112;R113;R114;R115 |
| `source_operating_ranges_refs` | References that informed the realistic sampling ranges for T, pCO2, pH, shear stress (NORSOK validity ranges; CCS dense-phase ranges) | R024;R025;R026;R027;R028;R006;R039 |

To look up any reference, e.g. `R020`:

```python
import csv
refs = {r["id"]: r for r in csv.DictReader(open("../references/references.csv"))}
print(refs["R020"]["title"], refs["R020"]["source_url"])
# -> "Improvements on de Waard-Milliams Corrosion Prediction and Applications
#     to Corrosion Management"  https://onepetro.org/NACECORR/...
```

**Reminder:** the numeric values themselves are computed from these cited
equations using sampled input conditions — they are not experimental
measurements reported in any single paper. Treat this as a transparent,
reproducible scaffold for studying model behavior and disagreement, not as an
experimental corrosion-rate database.
